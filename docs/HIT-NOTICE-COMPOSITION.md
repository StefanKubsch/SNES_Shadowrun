# Hit notice composition

The harmless-hit warning and karma penalty in [object-hit.mjs](../src/game/object-hit.mjs)
compose the window, text, thirty counter waits, confirmation and release directly.
The original call sites 80:87AF and 80:87F5 no longer create internal JSL frames.
The counter word, pad chronology, window uploads, hit count, result and karma
retain the existing contracts. The script/native outer adapters remain separate.

[hit-notice-caller.test.mjs](../tools/hit-notice-caller.test.mjs) compares both
notices against the frozen caller across counts, karma limits, upload wrap,
confirmation keys and budgets. Its delay classifier uses the thirty counter
changes before the first pad read, without reading CPU return words.
[hit-notice-flow.test.mjs](../tools/hit-notice-flow.test.mjs) rejects CPU stack
helpers and checks every budget-one pause, zero budget, counter wrap and repeated
completion. All five golden traces remain binding and unchanged.
