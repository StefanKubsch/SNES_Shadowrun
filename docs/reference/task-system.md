# Task system

Reference for the original task heap, frame initialisation, task list,
running heap frames, native state actions, task creation by native `$A9`,
the `$AC/$CF/$63` caller actions, the `$D9` arithmetic and the shared
native scratch `$A2`. It condenses the former German topic contracts
(TASKALLOKATION, FRAMEINITIALISIERUNG, TASKLISTE, LAUFENDER-HEAP,
ZUSTANDSAKTIONEN, A9-TASKERZEUGUNG, AC-DATENZUSTAND, CALLERAKTIONEN-CF-AC-63,
D9-ARITHMETIK, NATIVE-SCRATCH-ALIASE). Slot data is in [slots.md](slots.md),
opcode and native handlers in [task-opcode-handlers.md](task-opcode-handlers.md)
and [task-natives.md](task-natives.md), shared terms in
[the reference index](README.md#shared-contract-terms).

Common rules: all operations are JavaScript data operations on the European
ROM (SHA-256 `91dbfecf…2f690`); CPU addresses are provenance, no machine
instructions run and no general RAM bus exists. Unknown bytes stay `null`
and are never zero-filled. Missing sources keep the pending request without
partial host effect (a porting preflight, not an original rollback). Probe
CLIs use unchanged original scripts with explicitly synthetic root
arguments; no scene, graphics, audio or elapsed time is claimed.

| <a id="taskallokation"></a>Original task heap (`$80:C242–C2C7`, init `$C1C0–C1C6`)                           | [Listings](../../analysis/task-heap.asm.txt) and [report](../../analysis/task-heap.json) (`npm run analyze:heap`). A block header is two words: size including busy bit 15, and offset of the next header. Header offsets are relative to `$03D2`; payload address = `$03D6 + header offset`. The initial block has `$07CC` payload bytes and next offset 0 (`$07D0` bytes covered); next offset 0 ends the list, offset 0 itself is the first block. **Search** always starts at offset 0, skips busy blocks and takes the first large enough free block; it splits only when the difference is ≥ 5 bytes (new header after requested payload + 4 header bytes, new free block gets difference − 4); differences 0–4 stay in the busy block; no even alignment; a zero request follows the same instructions. A too small free block whose successor is also free is **merged** (size + successor size + 4, successor's next offset taken over, compare again); a busy successor is skipped. **Release** (`$C2BD`) clears only bit 15; it neither merges nor clears payload, so merges happen lazily and persist even after a failed request. **Return registers:** success A = `$03D6 + header offset`, X = header offset; busy end block A = `$0000` (its next offset), X = its header offset; too small free end block A = (block size − request) & `$FFFF`, X = its header offset. There is no uniform error value; a large request can give a return word without bit 15, so a sign test would be wrong. The caller `$C2F8` continues frame initialisation with A as address without a success check. **Header size** `$C2E1–C2F2`: A = 0, M 8-bit, CLC, add both header bytes, ADC `$17` with the carry kept, then M back to 16-bit: allocationBytes = ((sum & FF) + $17 + (sum > FF ? 1 : 0)) & FF (lost high bits are not restored); all 937 profiles checked, largest original request 67 bytes. **Task slot list** is separate: `$C1A6–C1BE` initialises 48 even offsets `$00–$5E`, free head `$024E` = 0; `$C333–C346` takes the head, stores the heap address at `$0252+X` and returns the task slot offset in X; `$C34D–C362` appends this root at the list end and returns the offset in A via TXA; `$C366` makes no immediate visit; `$A8EF–A8F1` stores A at `$1350+slot`. That word is **the original task slot offset**, neither heap address nor host task ID. Cursor `$0250` and argument word `$0000` are not changed by root append. A negative free head branches at `$C336` straight to RTS `$C349` (no capacity error handler).                                                                                                                                                                                                                                                                                                                                                                                                                 | `proof/script/task-heap.mjs`: `createTaskHeap()` with `allocate(byteLength)`, `release(blockOffset)`, `snapshot()` (copies active headers and all written header bytes; old header bytes stay and new headers may overwrite them at odd overlaps; payload bytes start unknown; a bounded model of this heap, no RAM bus). `allocate` reports `allocated`, `accumulatorWord`, `blockOffset` (`allocated` is API information, not an original register). `release` is limited to active known headers (repeated release covered; other offsets `task_heap_header_required` without change — a porting limit, the original has no such test and could alter payload or obsolete header bytes).
