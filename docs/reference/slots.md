# Slots and slot actions

Reference for the game slot table (44 even offsets `$00–$56`), its
initialisation, creation (native `$A9`) and release (`$B9`), the slot actions
called from scripts (`$02`, `$4F/$50/$51`, `$6A`, `$83`, `$D2`, `$D9`), helper
`$A985`, the bank 8C and target data providers and the slot motion body.
It condenses the former `SLOT*` contract files; the motion helpers are in
[movement.md](movement.md) and the shared terms in
[the reference index](README.md#shared-contract-terms).

Common rules: native operations in `proof/state/` check all needed sources
before any write and keep the pending native request unchanged on a missing
source (a porting preflight, not an original rollback); seed functions are
explicit source data or labelled test fixtures, never in-game
initialisation; probe commands use unchanged original scripts with an
explicitly synthetic control shell; no scene, graphics, audio or elapsed time
is claimed.
