# Movement (motion) routines

Reference for the original motion pipeline of the main loop: the gate
`80:8000`, the prefix `DE94`, the AFC4 sequence (prelude `8799`, the motion
body with its six helpers, post-processing `AC2F`), the scene transition
`A4BF` and the reset chain `BCB2`. It condenses the former `BEWEGUNG*` contract
files; the motion body itself is in [slots.md](slots.md#slotbewegung) and the
shared terms in [the reference index](README.md#shared-contract-terms).

Common rules: entry E0/M0/X0, D=0, binary arithmetic; the real main loop DBR
and original list initialisation (first list at 7E:DEAC, DEAA writer) are
open; native operations in `proof/state/` work on explicitly supplied bytes
(`createSlotMotionData()`), plan every write first and apply only a fully
covered plan (a host guarantee, not an original rollback); the probe
commands of `tools/run-slot-action-ac.mjs` use original scripts 252/217 with
explicitly synthetic orchestration and fixtures; nothing here proves a
scene, a collision answer, graphics, audio or elapsed time.
