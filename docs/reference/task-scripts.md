# Task scripts: Script52, bodies and yields

Reference for script opcode 52 (call a child script), its argument prefix,
stack switch, yield and resume, and for the whole original script bodies
proven natively. It condenses the former `RENDER-TASK-SCRIPT-*` and
`RENDER-TASK-CHILD-YIELD` contract files; shared terms are in
[the reference index](README.md#shared-contract-terms). Current work:
[PROJECT-STATUS.json](../PROJECT-STATUS.json); historical state and body lists:
[PORTIERUNGSSTAND.json](../PORTIERUNGSSTAND.json).

Common rules for body contracts: header, whole original bytecode and the
following fetch high byte are checked per body; only really reached ROM words
are pinned; callers, frames, records, heap, windows and device/wait/input
values in the probes are synthetic observations; helpers, polls, prefixes and
blocked readiness never count as bodies; a late failure discards only the
current segment, earlier committed yields remain; a continuation needs the
last really committed, branded plan of the same provider.

### Limits

The composition supports a finite parent with exactly one child 04B, 33D,
10E, 0C8, 6F or 0D2, without parent local call or loop. Parent 9F is proven
for 15C/15E/15F/164 and 28C. 15F/164 keep both original money comparisons
to 1. Other child types need their own frame, argument, window, wait/input
and return owner proof. No CPU/emulator execution, scene initialisation,
scheduler, time or frame integration.
