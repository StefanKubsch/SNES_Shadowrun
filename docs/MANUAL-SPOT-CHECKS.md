# Spot checks against the Nintendo Development Manual

Historical check note of 2026-10-17, code base `f828fc68`. It records checks
already carried out and extends no source contracts or runtime promises. The
current project status is only in the project status files. Translated from
the former German `MANUAL-STICHPROBEN.md` (original wording at git commit
20c7b6c9).

Source is the local [Nintendo Development Manual Book I](../Ressources/book1_text.pdf),
SHA-256 `f1405241000046abba7849376d2ec53cf85f1ad2e9950d69a7c2cf1f3ff6b791`.
PDF pages count from one. The searchable text layer was evaluated; a full
visual check of the diagrams or a run on original hardware was not part of
these spot checks. The extra check runs were executed once in the terminal; no
permanent tests were created. Results, parameters and limits are kept below even
though the original temporary logs (in the Windows temp folder) may no longer
exist. Targeted use of the manuals is governed by
AGENTS.md.
