# Shadowrun SNES Enhanced: Native Browser Port

This port of the classic 1993 Super Nintendo game is a complete disassembly and implementation in JavaScript. This is NOT an emulator, all code runs native in your browser, the original ROM ist not needed since all content is reversed-engineered.

At this point, the game is clearly targeted to be played on a computer: Browser, mouse/keyboard or controller. Sorry, no touch at the moment!

## In addition to the complete game, it includes the following enhancements:

- a newly recorded soundtrack by [Julian Daniels](https://juliandaniels.com/)
- customizable controls (mouse/keyboard/controller)
- full German and English localization
- optional highlighting of interactive objects in the game
- optional bug fixes for the original game
- optional cheats
- 2 or 4 in-game save slots
- direct access to the secret “debug room”
- credits can be accessed from the in-game startmenu
- a searchable handbook
- a CRT filter that models the signal path from the Super Nintendo to a Sony PVM-20M2E CRT monitor based on technical specifications (optional, but activated by default)
- modeling of the Super Nintendo’s audio output including analog filters (optional, but activated by default)
- some performance fixes killing annoying delays and slowdowns

## Why this game?

I’ve been a fan of the pen-and-paper role-playing game “Shadowrun” since the early ’90s. The blend of cyberpunk, fantasy, and magic is unique, and when the Aussies from Beam Software ported the game to the Super Nintendo in 1993, I wasn’t the only one who was thrilled: an ambitious role-playing game mixed with a point-and-click adventure - quite extensive by the standards of the time - that wonderfully captures the spirit and core mechanics of the pen-and-paper original, critically acclaimed by players and gaming magazines.

Unfortunately, the controls were always a bit clunky with a controller, there were a few (very few...) game-breaking bugs, and for 20 years I’ve been toying with the idea of porting this game. Here it is now, almost completely disassembled and in readable code, with some nice quality-of-life features.
